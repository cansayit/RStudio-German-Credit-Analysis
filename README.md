# RStudio German Credit Analysis

Bu projede German Credit veri seti kullanılarak RStudio ortamında kredi riski sınıflandırması gerçekleştirilmiştir.

## Yapılan çalışmalar
- Veri ön işleme ve temizleme
- ggplot2 ile veri görselleştirme
- Karar ağacı ile sınıflandırma
- Model performans değerlendirmesi
- 10 katlı çapraz doğrulama ile optimizasyon

## Sonuçlar
- İlk model doğruluğu: %69,50
- Optimize edilmiş model doğruluğu: %70,50
